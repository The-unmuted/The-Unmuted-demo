# 性骚扰模拟器：案例依据与校对清单

_更新日期：2026-10-14。适用文件：`src/data/simulations/sexual-harassment.json`。_

## 用途与边界

本清单记录“TA被性骚扰了该怎么做”模拟器 2026 年重构所参考的裁判文书和官方案例材料，方便公益律师、内容审核人员和团队成员逐项复核。

- 模拟器是经合并、匿名化和改写的教育情境；不复刻某一名当事人或某一案件的完整经过。
- 选项用于练习安全、求助、留存记录、单位处理和儿童保护之间的取舍，不预测拘留、立案、判刑、赔偿、处分或调取监控等结果。
- 性骚扰、猥亵、强制猥亵及其他法律定性均取决于具体事实、证据与法定程序；用户无需自行选择罪名。
- 具体法律文本、救济期限、当地受理机制和对外援助号码上线前均应由合格律师及当地服务机构复核。

## 设计核对项

1. **安全高于取证**：所有涉及封闭空间、车辆、夜间道路和突发触碰的路线，均不把继续停留、对质或取得“明确承认”设为义务。
2. **不把创伤反应当成失误**：僵住、顺从求生、延后讲述、先拉黑、先离开或先就医不扣分；仅对可避免且会增加即时风险的处理方式提示风险。
3. **记录讲完整性，不讲万能证据**：消息、平台回执、单位投诉、视频、场所出入、证人、首次披露、医疗记录和正式文书各自只能证明一部分，需根据事实相互印证。
4. **单位义务可操作**：场景提示用户询问“谁调查、何时处理、如何临时隔离、保密范围、防报复措施”，但不承诺单位必然处分或给出某一结果。
5. **未成年人优先保护**：不要求孩子完整讲述、不先联系可能施害的成年人、不公开传播；由安全监护人和具备儿童保护能力的专业渠道处理后续。

## 建议上线前审核

- 由公益律师确认每个涉及《民法典》第 1010 条、单位防治义务、治安/刑事边界和救济表述的准确性。
- 由儿童保护专业人员审核未成年人场景的语言和转介路径。
- 由产品团队按地区检查 110、12338、12348 与援助页条目是否仍可用、是否适用。
- 每次更新案例材料后，复查情景用语是否把个案结果误写成普遍保证。
