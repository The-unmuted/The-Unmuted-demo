# "模拟"功能 — 调研与设计方案（草案，待 Katie 确认）

_2026-07-30 起草。目标：参照"同类产品"的选择式模拟机制，做一个中国大陆版"从案发到结案"的报案流程模拟器，让用户在安全的环境里预演整个过程，并在结局复盘时看到"哪个环节的选择出了问题"。_

---

## 一、关于参照对象"同类产品"

微信小程序的内容封闭在微信生态内，公开网络上几乎检索不到"同类产品"的第一手界面和分支细节（搜到的多是各地人社局官方仲裁小程序）。**需要 Katie 提供**：小程序内几张关键截图或一段录屏（场景选择页、一个决策点、结局复盘页），我们据此对齐它的交互模式。

从公开信息能确认的这类产品的通用模式（也是我们要学习的核心）：

1. **代入式**：用户以第一人称身份进入一个具体处境（"你被裁员了"）；
2. **决策点驱动**：每一步给 2-4 个现实中真实存在的选项（签字/不签、先谈/先仲裁）；
3. **选择有后果**：不同选择进入不同分支，后果符合真实法律规则；
4. **结局复盘**：结束时告诉你哪一步选错了、正确做法是什么、依据是什么条文。

这个模式对我们的价值：**受害者最大的困境不是"不知道有法律"，而是在慌乱中不知道每一步该怎么选，以及事后才发现关键窗口已错过**（没验伤、洗了澡、签了谅解书）。模拟器让她在安全的时候把这条路先走一遍。

## 二、中国大陆流程调研（模拟器的事实骨架）

### 2.1 通用刑事主线（所有涉罪场景共享）

```
案发 → 报案(110/派出所)
     → 受案登记（公安应制作受案登记表并出具【受案回执】——用户常不知道可以索要）
     → 立案审查（原则≤3日；需查证线索≤7日；重大疑难经批准可延至30日）
     ├─ 立案 → 侦查（讯问、勘验、鉴定、调取监控）→ 强制措施（拘留/逮捕/取保）
     │        → 侦查终结移送检察院 → 审查起诉（1个月，可延15日）
     │        ├─ 提起公诉 → 一审开庭 → 判决 → 上诉期10日 → 生效/二审 → 结案
     │        └─ 不起诉 →（被害人可7日内申诉，或直接向法院自诉）
     └─ 不予立案 → 收到【不予立案通知书】后 7日内 向原公安机关申请复议（公安7日内答复）
                → 仍不服：申请检察院【立案监督】（应当立案而不立案是法定监督情形）
```

被害人全程的权利节点：委托诉讼代理人、申请法律援助（12348）、提起附带民事诉讼、对不起诉决定申诉。

### 2.2 家暴（分支最丰富，建议第一期做）

家暴是**多轨并行**的，这正是普通人最容易走错的地方：

**轨道 A — 报警（行政/刑事）**
- 出警 → 制作出警记录、询问笔录（这些是日后保护令和离婚诉讼的核心证据）
- 伤情鉴定：轻微伤 → 治安处罚（拘留/罚款）或【告诫书】；轻伤及以上 → 刑事立案（故意伤害罪）
- 【家暴告诫书】（反家暴法第16条）：情节较轻不予治安处罚的，公安**应当**出具——很多用户不知道可以主动要求；告诫书本身就是法院认定家暴的证据
- 常见错误分支：接受"口头调解"就离开，什么书面材料都没拿到

**轨道 B — 人身安全保护令（民事，不需要离婚、不需要对方到场）**
- 依据：反家暴法 + 最高法2022年《关于办理人身安全保护令案件适用法律若干问题的规定》
- 证明标准是"存在较大可能性"（低于一般民事的"高度可能性"——多数人以为要"铁证"而放弃）
- 可用证据（2022规定明确列举）：出警记录、报警回执、询问笔录、告诫书、悔过书/保证书、伤照、录音、聊天记录、向妇联/居委会/单位求助的记录
- 法院受理后 72 小时内作出裁定，紧急情况 24 小时
- 措施：禁止施暴、禁止骚扰跟踪接触、责令迁出住所等；违反保护令可拘留罚款，情节严重构成拒执罪
- 无民事行为能力/受强制无法申请的，近亲属、妇联、居委会等可代为申请

**轨道 C — 离婚诉讼**
- 家暴是法定判离情形；无过错方可主张离婚损害赔偿（民法典1091条）
- 证据链与轨道 A/B 完全复用——这是"每次都报警留痕"的意义所在

**家暴场景的典型"错误环节"（复盘素材）**：没报警只忍让（无任何官方记录）；报警后不验伤；不知道索要回执/告诫书；以为不离婚就不能申请保护令；把施暴者的保证书扔掉（它是证据）；伤情鉴定拖过了最佳时限。

### 2.3 性侵（刑事公诉主线 + 黄金取证期）

- 强奸/强制猥亵是**公诉案件**——立案后由国家追诉，不存在"自己撤案"，但报案时机和物证保全极大影响成案率
- **黄金72小时**（模拟器最重要的教学点）：不洗澡、不清洗衣物、尽快到医院做检查取样（DNA/损伤记录）、保存现场；监控录像通常只保存 15–30 天，调取要趁早
- 流程按 2.1 主线走；重大疑难立案审查原则不超过 7 日
- 被害人保护：涉个人隐私案件**不公开审理**；身份信息和性侵细节全程保密（对未成年人另有"一站式"取证、一次询问原则等专门规定——两高两部《关于办理性侵害未成年人刑事案件的意见》）
- 平行救济：附带民事诉讼（医疗费、心理康复费）；不立案 → 复议 + 检察监督
- 典型错误环节：第一时间清洗；因羞耻拖延数月报案；与对方"私了"签谅解协议后再报案（大幅增加认定难度）；自行对质打草惊蛇（对方删证据）

### 2.4 性骚扰（三条并行路径，多数人只知道其一）

1. **民事**：民法典 1010 条确立独立的"性骚扰损害责任纠纷"案由，可直接起诉行为人索赔并要求停止侵害、赔礼道歉
2. **治安**：治安管理处罚法（猥亵、发送淫秽信息侮辱他人可拘留）——注意**治安案件 6 个月追诉时效**，拖过就无法处罚
3. **职场路径**：单位有防治性骚扰的法定义务（民法典1010条第2款）；向单位投诉 → 单位不作为可向妇联(12338)/工会/劳动监察投诉；因骚扰被迫离职可主张经济补偿
- 典型错误环节：删掉恶心的聊天记录（销毁了唯一证据）；只在内部忍让超过 6 个月（治安时效过了）；没有书面向单位投诉（后续无法证明单位知情不作为）

### 2.5 与非默现有功能的天然衔接

模拟器每个"你现在应该固定证据"的节点，都可以指向**已有的存证功能**；每个"你可以打这个电话"的节点，指向**援助目录**的真实条目（12338/12348 + 城市资源）。模拟不是孤立玩法，而是把用户引向真实能力。

## 三、模拟器机制设计

### 3.1 交互形态（对齐"同类产品"模式）

- 入口选择处境："我遭遇了…" → 家暴 / 性侵 / 性骚扰（复用 D-021 的情形分类语言，永不只写"家暴"）
- 每一幕：一段第二人称场景描述（克制、不渲染细节）+ 2–4 个选项
- 每个选择立即给出**短反馈**（这个选择带来了什么），然后推进到下一幕
- 结局页：这条线走到的结果（案件走向）+ **复盘清单**：绿色 = 做对的关键选择；红色 = 出问题的环节，配"正确做法 + 白话依据"
- 全程可随时退出；不保存任何选择记录（或仅本地保存）；快速离开按钮照常可用

### 3.2 内容与代码分离（沿用 aidDirectory 的成功模式）

场景写成结构化 JSON（`src/data/simulations/家暴.json` 等），示意：

```json
{
  "id": "dv-01",
  "scene": { "en": "...", "zh": "他第一次动手打了你。伤在手臂，不重，但你很害怕。" },
  "choices": [
    { "text": { "zh": "打 110 报警" }, "next": "dv-02-police", "flags": ["reported"] },
    { "text": { "zh": "忍下来，家丑不外扬" }, "next": "dv-02-silent", "flags": ["no-record"] },
    { "text": { "zh": "拍下伤处照片，先记录下来" }, "next": "dv-02-evidence", "flags": ["evidence-photo"] }
  ]
}
```

结局复盘由走过的 `flags` 生成（如 `no-record` → "没有任何官方记录，后来的保护令申请缺少最有力的证据"）。这样：
- 法律内容团队/法律顾问可以直接校对 JSON 文本，不用碰代码
- 每条复盘规则可标注依据条文，像援助目录一样可核实
- 未来加新场景 = 加一个 JSON 文件

### 3.3 安全与伦理设计（这个功能的特殊红线）

1. **不渲染暴力/侵害细节**——场景描述只写处境和情绪，不写过程；性侵场景尤其克制
2. **每一幕都有"我现在就需要真实帮助"出口**——一键跳到援助目录/SOS，模拟随时让位于现实
3. **明确免责声明**：这是教育模拟，不构成法律意见；具体案件请打 12348
4. **不评判受害者**："错误环节"的复盘语言指向系统和方法（"这一步缺少了官方记录"），永不指责用户本人（"你不该忍"→ 禁止这种表述）
5. **内容需法律顾问/公益律师校对后才能上线**——和援助目录"先人工核实再收录"同一个原则；结案率、量刑等数字不写具体承诺

### 3.4 页面结构调整

- 底部导航：SOS / 证据 / **援助**（心理+法律合并，顶部分段切换，城市筛选共用）/ **模拟**
- 合并援助页是低风险改动（两页已共用 `AidResourceList`）；"模拟"占用空出的第 4 格

### 3.5 分期建议

| 期 | 内容 | 说明 |
|---|---|---|
| 一期 | 援助页合并 + 模拟框架 + **家暴一个完整场景**（约 12–18 幕、3 条主线、5–6 个结局） | 家暴分支最丰富、法条最清晰（反家暴法+2022规定），最适合打样 |
| 二期 | 性骚扰场景（三路径分支） | 决策树中等复杂 |
| 三期 | 性侵场景 | 内容最敏感，写作和校对要求最高，放最后 |

## 五、主要依据与来源（团队校对用）

- 最高人民法院《关于办理人身安全保护令案件适用法律若干问题的规定》(2022)：证据列举、"较大可能性"标准 — gongbao.court.gov.cn
- 七部门《关于加强人身安全保护令制度贯彻实施的意见》(2022)：告诫书与保护令衔接、代为申请
- 《反家庭暴力法》(2016)：第16条告诫书、第23-32条保护令
- 两高两部《关于办理性侵害未成年人刑事案件的意见》(2023)：立案审查≤7日、一站式取证、隐私保密 — spp.gov.cn / court.gov.cn
- 公安机关办理刑事案件程序规定：受案回执、立案审查3/7/30日、不予立案7日复议
- 《民法典》第1010条（性骚扰）、第1091条（离婚损害赔偿）；《治安管理处罚法》第22条（6个月时效）、第42/44条
- 检察机关立案监督范围（应立不立/不应立而立/逾期不决定）— spp.gov.cn
